# 🔍 GitScope

### Analyze Any GitHub Profile with Beautiful Insights

A modern GitHub Portfolio Analyzer that provides repository statistics, portfolio score, language distribution, and developer insights using the GitHub REST API.

🌐 **Live Demo:** https://rachnagarg-commits.github.io/GitScope/

# ✨ Features

- 🔎 Search any public GitHub profile
- 👤 Display user profile information
- 📊 Repository analytics dashboard
- ⭐ Total Stars
- 🍴 Total Forks
- 📁 Total Repositories
- 🏆 Portfolio Score
- 💻 Language Distribution Chart
- 🔍 Repository Search
- 📋 Repository Sorting
- ⚡ Animated Counters
- 💎 Modern Glassmorphism UI
- 📱 Responsive Design
- 🌐 Powered by GitHub REST API

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/RachnaGarg-commits/GitScope.git
```

Go to the project folder

```bash
cd GitScope
```

Open

```
index.html
```

or run with Live Server in VS Code.
